5. TRES TRAMPAS MATEMÁTICAS CRÍTICAS EN QAP10
EVITAR DESCALIFICACIÓN
Conteo Único de Pares ($i < k$): Las bases estipulan que cada par de elementos se evalúa una sola vez. Si en el código utilizas bucles con
$i \ne k$, el costo se duplicará exactamente arrojando 48 y 64 en vez de 24 y 32, invalidando la evaluación de control.
Distinción entre Costo Real y Energía Penalizada: El Hamiltoniano arroja $H(x) = C(x) + \text{Penalizaciones}$. El resultado que se expone
al jurado y con el que se calcula el Gap (%) debe ser exclusivamente el costo factible $C(x)$.
Límite Físico de Memoria para $N=10$: Para 10 elementos se requieren 100 variables binarias. Simular 100 cúbits con statevector requiere
$2^{100} \times 16$ bytes de memoria (físicamente imposible). Si el usuario selecciona $N=10$, el sistema debe ejecutar una heurística
clásica o subcircuito cuántico por descomposición.
